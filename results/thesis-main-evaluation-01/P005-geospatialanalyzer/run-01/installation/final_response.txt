**Actions performed**
1. Explored the repo at `/workspace` (GeospatialAnalyzer, NestJS/Node 24, pnpm 11).
2. Confirmed Node/pnpm were absent locally but Docker 29.7.2 with Compose v5.5.0 was available; pulled `postgis/postgis:15-3.4`.
3. Ran `docker compose -f docker-compose.yml up --build -d`. First run built the app image but the app container crashed with `Error: EISDIR: illegal operation on a directory, read` (from `ConfigModule.loadEnvFile`).
4. Root cause: the repo had no `.env.dev` file, so the compose bind mount `./.env.dev:/app/.env.dev:ro` created a *directory* at `/app/.env.dev`; NestJS tried to read it as a file. The guide itself states `.env.dev` must be created from `env.dev.sample`.
5. Fixed by `docker compose down`, `rm -rf .env.dev`, `cp .env.dev.sample .env.dev`, then restarted the stack.
