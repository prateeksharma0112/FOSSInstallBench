### Abandoned attempt
The guide's dev command `ddev drush site:install --yes --existing-config` failed reproducibly during config import with:
`The service "openculturas_openstreetmap.addressLookup" has a dependency on a non-existent service "geocoder.throttle".`
This is caused by `openculturas_openstreetmap` being enabled before the `geocoder` module in `config/sync/core.extension.yml`, while its `AddressLookup` service autowires `geocoder.throttle` — a bug in the checked-out commit's config ordering, not an environment problem. Installation was recovered using the alternative documented install path (`ddev composer run si`), which enables modules in dependency order.
