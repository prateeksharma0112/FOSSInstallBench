**Installation steps from the guide:**
- `just setup` — cargo fetch, pnpm install, frontend workspace packages, domain WASM, Keycloak theme. ✅
- `just build` — frontend production bundle + backend release binary (`bin/green-ecolution`), handbook PDF, Keycloak theme jar. ✅
- `just infra-up` — started Postgres/PostGIS, Keycloak, Traefik, Valhalla, Streamlet, pgAdmin.
- `just migrate-up` — applied 67 migrations (verified 27 tables + `_sqlx_migrations` in the DB).
- Started the backend (release binary on :3030, `APP_ENVIRONMENT=local`) and frontend Vite dev server (:5173), both routed through Traefik on port 3000.

### Environment-specific adjustments (not in the guide)
The container runs Docker-in-Docker on a cgroup v2 hierarchy in *threaded* mode under `/sys/fs/cgroup/docker`, which makes `runc` fail for any container requesting CPU/memory resource limits ("cannot enter cgroupv2 ... in threaded mode"). The `valhalla` and `streamlet` compose services declare `deploy.resources` limits and thus failed to start. To work around this I used a compose override (`/tmp/override.yaml`) that resets `deploy.resources` for those two services; all other services started directly. This is an infrastructure limitation of the sandbox, not a defect of the guide or project.
