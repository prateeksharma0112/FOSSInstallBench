The ozgxplanung (xPlanBox) software was successfully built/installed from source.

## What was done
This repository is the xPlanBox source tree (Maven multi-module project, version 9.4-SNAPSHOT). Per the README's "Anwendung erstellen" section, the documented installation method is a Maven build producing the application binaries.

**Prerequisites installed in the container (not present initially):**
- OpenJDK 17 (17.0.20.1) via `apt-get install openjdk-17-jdk` — README requires JDK 17.
- Apache Maven 3.9.9 downloaded from archive.apache.org and installed at `/opt/apache-maven-3.9.9` (Ubuntu's packaged Maven is 3.6.3; the root POM enforces `<maven.version>3.9.0`).
- `unzip` via apt.

**Build (final, successful method):**
- `mvn -B clean install -DskipTests` in `/workspace` → **BUILD SUCCESS**, 60/60 modules, total time 12:33 min. Tests skipped because no PostgreSQL/RabbitMQ/S3 services are available (README explicitly documents `-DskipTests` as the supported option when unit tests cannot run).
- `mvn -B install -P distribution -DskipTests` → **BUILD SUCCESS**, total time 5:56 min, which adds the `xplan-distribution` assembly module.
