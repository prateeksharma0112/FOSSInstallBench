**Known limitation:** Two `postinstall` data fetches (`scripts/bip-recent.sh`, `scripts/wachstum-recent.sh`, plus `einwohner.sh`) call the Regionalstatistik Genesis API and require `REGIONALSTATISTIK_USER`/`REGIONALSTATISTIK_SECRET` credentials (as the project's Dockerfile mounts these as build secrets). They return non-zip error payloads, so `assets/data/wachstum-recent.csv`, `bip-recent.csv`, and `einwohner.csv` are missing. Consequently the `/klima`, `/energie`, `/mobilitaet` routes return 500 (unresolved CSV imports) while `/` returns 200. This is a data-credential/upstream service limitation, not a dependency-installation failure. The application is installed and runnable per the guide.
