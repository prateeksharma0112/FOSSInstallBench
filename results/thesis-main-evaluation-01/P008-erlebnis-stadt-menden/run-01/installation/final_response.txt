## Installation Report — Erlebnis.Stadt Menden

I attempted to install the monorepo at commit `e5a8336`. The repo has three workspaces: `backend/` (Kotlin/Spring Boot), `app/` (Ionic/Angular, Nx/pnpm) and `cms/` (Angular, Nx/pnpm).

### What was done
- **Installed prerequisites** (none were preinstalled): Node.js v22.23.2 (`/opt/node`, symlinked into `/usr/local/bin`), pnpm 10.20.0 and nx globally, JDK 21 (`/opt/jdk21`) and JDK 25 (`/opt/jdk25`).
- **Backend (`/workspace/backend`) — SUCCESS:**
  - README said GitHub token/JDK 21 are required, but `settings.gradle.kts` resolves `io.swcode.*` from the *public* `https://urbo-maven.s3.eu-central-1.amazonaws.com/releases`. No token needed.
  - The build actually requires JDK 25 (not 21 as the README states); confirmed via `.github/workflows/backend.yml` (`javaVersion: "25"`). Failed with JDK 21 (`Dependency requires at least JVM runtime version 25`), succeeded with JDK 25.
  - `./gradlew :menden-app:compileKotlin` → BUILD SUCCESSFUL; `./gradlew :menden-app:bootJar` → produced `/workspace/backend/menden-app/build/libs/menden-app.jar` (174 MB).
  - Started the docker-compose stack in `/workspace/backend/docker` (`docker compose up -d`): postgres, keycloak, meilisearch, localstack, wiremock all up/healthy.
  - Ran the jar; Spring Boot started, imported data, and `curl http://localhost:8081/health` returned `{"groups":["liveness","readiness"],"status":"UP"}`.
- **Frontend `app/` and `cms/` — FAILED:** `pnpm install` in both workspaces fails with `ERR_PNPM_FETCH_401 GET https://npm.pkg.github.com/download/@sw-code/... 401 Unauthorized`. The projects depend on `@sw-code/urbo-*` packages hosted in the private GitHub Packages registry (`@sw-code:registry=https://npm.pkg.github.com` in each `.npmrc`). The guide requires a GitHub Personal Access Token, but none was provided in the environment; no public mirror exists (npmjs.com 404, GitLab package registry empty). This is an external-credential blocker, so `app` and `cms` could not be installed or built.

### Outcome
The backend installed and ran successfully, but the web frontend (`app`) and CMS (`cms`) could not be installed because the required private GitHub Packages credentials were not available. Overall installation is therefore incomplete.

### Known commands / access points
- Backend jar: `/workspace/backend/menden-app/build/libs/menden-app.jar`, run with `/opt/jdk25/bin/java -jar ...` (API on :8080, management/health on :8081).
- Infra ports: postgres 5432, keycloak 8090, meilisearch 7700, localstack 4566, wiremock 3000.
- Frontend (when credentialed): `cd app && pnpm install && pnpm nx serve erlebnis.stadt`; CMS: `cd cms && pnpm install && pnpm start`.
