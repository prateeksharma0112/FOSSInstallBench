## Limitations / notes
- The production reverse proxy, TLS, real SMTP relay, OIDC/SSO (§8) and Moodle bridge (§9) were not configured; these require external infrastructure (public DNS/TLS, mail server, IdP, Moodle) not present here and are documented as optional/follow-on steps. The mobile app-link fingerprint variables were left empty, consistent with documented defaults.
- Validation used the documented `docker-compose.local.yml` overlay because no public DNS/TLS/reverse proxy exists in this environment; the base `docker-compose.yml` intentionally publishes no host ports, and the summary correctly reflects that.
- During validation, my `docker compose run --rm` backup check caused Compose to recreate the `postgres` container under the base file, dropping its host 5433 port mapping. This is a validation side-effect, not an installation defect; data persisted and all services remained healthy afterward.

Overall, the core installation described by the guide (secrets, `.env`, stack startup, migration, health checks, school/admin onboarding, backups) is complete and demonstrably operational.
