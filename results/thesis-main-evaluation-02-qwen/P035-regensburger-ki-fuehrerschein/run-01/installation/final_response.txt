Installation of the Regensburger KI-Führerschein (Next.js 15 + React 19 learning platform) completed successfully per the provided Installation.md guide.

What was done:
1. Prerequisites: Node.js and Bun were absent, so I installed Node.js v22.23.3 (official linux-x64 tarball, satisfies the "Node.js 18+" requirement) to /usr/local, and Bun 1.4.3 (official GitHub release binary) to /usr/local/bin/bun. Also installed unzip via apt to extract the Bun zip.
2. Per the guide, ran `bun install` in /workspace (the repository, already checked out at the predefined SHA) — 511 packages installed successfully. 3. Per the guide's Konfiguration section, created /workspace/.env.local from .env.example (MongoDB left as the optional placeholder; set a concrete dev DASHBOARD_PASSWORD).
4. Started the dev server with `bun dev` (Next.js 15.4.10 + Turbopack) in the background; log at /tmp/devserver.log; server ready in ~2.3s.
