**Obstacles resolved (config/cred issues, not environment blockers):**
- The `latest` image is **v2.5.1** but the checked-out repo/template is **v2.4.0** (a `TAG=latest` drift). The v2.5.1 ASR service requires a `presets:` config section; the example template only has the legacy `model_settings` block, causing every job to fail with `Preset default not found`. I added the `presets:` section (id `default`, base `whisperx`, whisper large-v3 CPU options) to `deployments/example-opencode/asr-service.cpu.default.yml` (42-line addition, the only repo file modified).
- The ASR service tried to download the gated `pyannote/speaker-diarization-3.1` & `pyannote/segmentation-3.0` models, which return **HTTP 401** without a real, access-approved Hugging Face token (only a placeholder was available). Since the pyannote backend unconditionally loads its model even with `diarize: false`, I removed the `diarize` process step from the preset to let the core Whisper ASR run.
