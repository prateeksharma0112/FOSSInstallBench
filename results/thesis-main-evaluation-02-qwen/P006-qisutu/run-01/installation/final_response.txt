Qisutu 2.0.2 was successfully installed at /opt/qisutu on Ubuntu 22.04 (container, no systemd). The documented flow was followed: source copied to /opt/qisutu, `QISUTU_INSTALL_LANGUAGE=de ./install.sh` completed system preparation (Apache, MariaDB, Perl modules, Apache site, systemd units, qisutu runtime user), and the 6-step web installer at http://127.0.0.1/qisutu/install.pl was driven non-interactively with curl. Database `qisutu` has 138 tables, admin account active with generated password, installed.lock created, daemon running as user `qisutu`, and a real agent-portal login with the generated admin password returns the dashboard. Because the container has no systemd, a transparent /usr/local/bin/systemctl shim (logging to /var/log/qisutu-systemctl-shim.log) managed apache2/mariadb/daemon processes; every systemd unit file was still created and the temporary install-complete units were removed after the daemon started, as the guide describes.
